# AI-Powered Chatbot

## Project Description

This project is an AI-powered retrieval-based chatbot developed using Python and Flask.

The chatbot receives questions from users, compares them with predefined questions in a knowledge base and returns the most relevant answer.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON

## Features

- User-friendly chatbot interface
- Retrieval-based response system
- Predefined knowledge base
- Question similarity matching
- Real-time responses
- Web-based interface
- Easy to extend with new questions and answers

## Project Structure

Task4_Chatbot/
- app.py
- chatbot.py
- requirements.txt
- README.md
- data/knowledge.json
- templates/index.html

## How to Run

Install the required package:

pip install -r requirements.txt

Run the application:

python app.py

Open the browser and visit:

http://127.0.0.1:5000
